InfiniSynapse 调用台账

比赛的前置准入条件要求「后端通过 Server API 调用 InfiniSynapse，且调用日志可在平台后台查验」。 这一页把编排真实发出的每一次调用逐条列出：时间、环节、承担的智能体、耗时与产出量； 平台回写了 taskId 的那些，可以直接拿号去后台按条核验。

调用链路
每次研判后端都按官方要求的顺序走完整条链路，顺序不能颠倒：
  1. 先建 SSE 长连接 GET /api/ai/events?connId=，否则会丢掉开头的事件
  2. 开联网检索 autoApprovalSettings.enableWebSearch
  3. 建任务 POST /api/ai/message 带 newTask
  4. 拿到 taskId 立刻 POST /api/ai/settings 显式锁定 deepseek-v4-pro，不依赖账户默认值
  5. SSE 流式 + GET /api/ai_task/tasks 轮询双保险取回结果
  6. POST /api/ai_task/setShare 生成平台公开链接，便于第三方核验
一次研判会打好几次引擎：慎思成文一次、质检评审一次、每轮返工各一次、 辩论开启时红队与裁判各一次。本页把它们逐条列出，不做合并—— 合并之后条数就对不上编排实际发生的动作了。平台回写了 taskId 的那些， 可以直接拿号去后台按条复查。
